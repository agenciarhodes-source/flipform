# GoJus — runtime Python nativo da Vercel

Substitui transporte base64 por manifesto pequeno com URLs R2 pré-assinadas pelo backend. A função Python GET dos originais e PUT do PDF de apresentação no prefixo tenants/<tenant>/gojus-temp/<uuid>.pdf, sem receber credenciais do R2 ou banco. Retorna apenas tamanho, páginas e SHA-256 calculado pelo worker. Backend confirma tamanho e tipo por HEAD, revalida manifesto e autorização e emite download R2 de 60 segundos. O hash reportado pelo worker não é uma verificação independente dos bytes gravados. Originais preservados. Limites 20 MiB entrada, 24 MiB saída, 120 páginas e 40 arquivos; ainda não são limites do GoJus.
