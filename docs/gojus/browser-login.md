# GoJus — credencial de navegador e teste de login

Não é API do GoJus. Perfil Desenvolvedor da empresa selecionada, grant gojus_robot ativo, RBAC e autorização de ambiente. Reutiliza cofre Universal Connect AES-256-GCM com AAD tenant/connection/provider; provedor reservado gojus_browser com enabled=false, nunca habilita sincronização. Rotas genéricas de listagem/alteração/revogação do registry excluem o provedor. Credenciais não são devolvidas à UI. Revogação local remove ciphertext, não altera a conta externa. Status de login é evidência histórica vinculada à versão cifrada, nunca sessão ativa. Requer nova senha após substituição; não guardar cookies.

Ambiente servidor: GOJUS_LOGIN_CONFIG_ENABLED=1 somente após aprovação, GOJUS_LOGIN_URL (URL HTTPS exata e verificada), UNIVERSAL_CONNECT_VAULT_KEY e UNIVERSAL_CONNECT_VAULT_KEY_ID existentes. Teste adicional GOJUS_LOGIN_TEST_ENABLED=1, GOJUS_LOGIN_WORKER_URL (HTTPS exato /v1/login-test, host controlado), GOJUS_LOGIN_WORKER_TOKEN (segredo forte). Worker separado: node workers/gojus/login-worker.mjs, instalação Playwright/Chromium pelo lockfile, proxy TLS privado para loopback 8766, mesmas GOJUS_LOGIN_URL e token, GOJUS_LOGIN_SUCCESS_URL exata verificada após login, GOJUS_LOGIN_EGRESS_VERIFIED=1 somente após comprovar política de rede que bloqueie todos os destinos exceto host autorizado com IP público fixado e sem DNS rebinding; navegador sem privilégios, sem acesso a rede privada, timeouts e limites CPU/memória. Não habilitar em produção neste PR. Sem valores reais no código, logs, prompt ou chat.

Seletores observados: E-mail, Senha, Entrar; evidência de sucesso somente URL exata + Pré-cadastro de Clientes + botão Pré-cadastrar cliente visíveis e formulário de login ausente. Seletores ainda NÃO verificados no GoJus real; desafios ou divergências exigem operador, sem contorno de MFA/captcha e sem repetição automática. Sessão efêmera sempre encerrada. Não clica em Pré-cadastrar cliente nem altera dados. Testes offline de regras e fail-closed; não há teste de login real ou deploy realizado. Nenhuma migração ou grant neste PR.
