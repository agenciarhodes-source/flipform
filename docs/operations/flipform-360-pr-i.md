# PR-I — Flip Intelligence executive snapshot
Base 43334f7fe6ddc850117a6cfeefd497c76531fe08; PR-H #666 merged.
Pure offline fixture-only analytics engine; no API, database, UI, provider calls, AI requests, jobs or production flag. Implements explicit single authoritative source per metric with tenant/account/connection and date basis, exact period coverage manifest, 48h freshness heuristic, no zero fill on missing coverage, unknown statuses or missing values. The threshold and freshness defaults are design choices for synthetic tests, not production SLAs. Amounts are minor units or micros, never combined across currencies. CRM win rate = won / closed within period, not leads-to-contract conversion. Order value is neither recognized revenue nor cash; open/overdue amounts due within period are not current total balance. Ads and organic ratios remain within the same source. No automatic joins, ROAS, forecasts, inferred cash or revenues. Equal adjacent periods only, no percentage change from zero; deterministic threshold change alerts for human review, not statistical anomaly detection or automatic recommendations. Unverified/stale data suppressed. No personal records or raw payload in output. Explicit mode fixture, productionReady false. Sources/manifests must come from trusted server code; this module does not authenticate callers or prove completeness. Synthetic input projections follow PR-H record semantics and explicit projected daily campaign/search grain; live adapters from PR-D/F/G/H still need server mapping, authorization, validation, storage, reconciliation and verified coverage. Real dashboards, CRM native pipeline metrics, forecasting and executive API/AI access are pending, must not represent fixtures as production. PR-N needs to validate the complete suite and operational gates, not just compile.
