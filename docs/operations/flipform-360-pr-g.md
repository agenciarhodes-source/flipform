## Delivered
Fixed read-only query plans and pure normalizers for Business Profile daily performance and review summary, YouTube daily channel activity, Search Console daily web search and bounded top 250 queries. Search Console POST is a read-only report query, not a provider mutation. Maximum window 31 days. Property/location/channel exact grant; cross-tenant duplicates rejected; account and connection tied to report receipt. No credentials, routes, transport, schema, scheduled jobs or UI. No raw review text or identity returned; review aggregate partial-response fields need validation with approved live API. Google Business Profile business.manage is a broad scope (not a readonly scope), so future transport must hard-allowlist read-only operations. YouTube read permissions must be validated for the exact authenticated channel. Search Console uses readonly scope and final web data, property aggregation. Preserve provider dates; no implicit UTC or Brazilian day alignment. GBP omitted dated value means zero only when a dated row exists. Missing days/metrics are never zero-filled. Search query results are top-only, not exhaustive; do not add to totals. CTR and position computed from clicks and impression-weighted position, not unweighted averages. No inferred revenue/conversions. Query strings can include personal data; keep in transient authorized context, apply privacy filtering before storage/display and restrict access, retention and downstream AI use. No personal query logging. No source payload persisted.
